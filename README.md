# GameApha - Bus Fever Party (Traffic Jam & Color Sort Game)

Cross-platform casual puzzle game built for **Web, Android, and iOS** inspired by Bus Fever Party.

## ?? Game Features
- **Grid-based Traffic Puzzle (6x6)**: Clear blocked paths for buses.
- **Color-Sorting Passengers Queue**: Match waiting passengers to color-coded buses.
- **Dynamic Boarding Docks**: Starts with 3 slots, increases as levels advance.
- **Rewarded Ad Bonus Slots**: Watch ads to unlock up to +2 extra boarding slots.
- **Multi-Platform Support**: Includes HTML5 Canvas/Vite Engine, Flutter + Flame Engine, and Unity Engine C# scripts.
